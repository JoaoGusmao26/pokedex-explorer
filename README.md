
## Como utilizar

1. Abra o arquivo `index.html` no navegador.
2. Digite o nome ou número de um Pokémon.
3. Clique no botão de busca.
4. Visualize as informações retornadas pela PokéAPI.
## API utilizada

Este projeto utiliza a PokéAPI para consultar informações dos Pokémon, como nome, número, imagem, tipos, altura, peso, experiência base e habilidades.

Endpoint utilizado:

https://pokeapi.co/api/v2/pokemon/{nome-ou-id}

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- PokéAPI
- Git e GitHub
## Compatibilidade

A aplicação pode ser executada em navegadores modernos com suporte a JavaScript e à Fetch API.
